# Condicionais e Controle de Fluxo

| Arquivo | Descrição Técnica |
|---------|-------------------|
| condicional-1.js | Verificação básica de maioridade utilizando estrutura if isolada. |
| condicional-2.js | Lógica binária com if/else e implementação equivalente via operador ternário. |
| condicional-3.js | Classificação de notas em múltiplas faixas de desempenho usando cadeia else if. |
| condicional-4.js | Mapeamento de siglas de UF para nomes completos via switch; sensível a espaços em branco. |
| aprovacao.js | Separação de alunos em arrays; contém erro lógico (inverte aprovação e reprovação). |

# Cálculos e Matemática

| Arquivo | Descrição Técnica |
|---------|-------------------|
| desconto.js | Função pura para cálculo de desconto percentual simples sobre preço base. |
| desconto%.js | Cálculo de pedido com cupom; aplica desconto sobre (valor + frete), mas subtrai apenas do base. |
| porcentual%.js | Cálculo de preço final com desconto agressivo (99%); retorna valor bruto sem formatação. |
| porcentual%2.js | Versão corrigida do cálculo percentual aplicando desconto padrão de 5%. |
| calculatora.js | Parser aritmético manual com suporte a parênteses aninhados; ignora precedência padrão (* antes de +). |
